# ECDICT dictionary data notice

`ngsl-dictionary.json` is a filtered and normalized subset of the ECDICT English-Chinese dictionary database.

- Source: https://github.com/skywind3000/ECDICT
- Fields used: word, phonetic, Chinese translation
- Filter: entries matching the NGSL word list bundled with WordLoop
- License: MIT; see `ECDICT-LICENSE.txt`

The data was downloaded from the upstream `master` branch on 2026-10-23. Translation line breaks were normalized for display. All original ECDICT copyright and license terms are retained in `ECDICT-LICENSE.txt`.
